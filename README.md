# cafe-central-app.

## Nombre del proyecto
Cafetería Central App

## Descripción
Aplicación web diseñada para gestionar el servicio de cafetería de una institución educativa. Permite administrar el menú, registrar pedidos, llevar control de inventario y dar seguimiento a pagos de forma sencilla y organizada.

## Problema que resuelve
Facilita la organización de pedidos, evita confusiones en la toma de órdenes, reduce tiempos de espera y permite llevar un control claro de lo que se vende y consume en la cafetería.

## Funcionalidades principales
- Visualización del menú con precios
- Realización y registro de pedidos
- Seguimiento de estado de pedidos
- Control de inventario de productos
- Gestión de usuarios (clientes y administrador)
